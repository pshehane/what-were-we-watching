# The Movie Database logo

`app/src/main/res/drawable/tmdb_logo.xml` is TMDB's own logo, taken from their
attribution page and converted from SVG to an Android vector drawable. The path
data, the three-stop gradient and the proportions are unchanged.

Source: https://www.themoviedb.org/about/logos-attribution

TMDB require this mark to be shown alongside the notice:

> This product uses the TMDB API but is not endorsed or certified by TMDB.

Both appear on the app's About screen. The logo is TMDB's trademark and is used
for attribution only; it is not covered by this repository's MIT licence.
